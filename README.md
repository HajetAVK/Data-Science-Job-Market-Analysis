# Анализ рынка вакансий в сфере Data Science (2020–2022)

## 📌 Описание проекта
В рамках проекта был проведен полный исследовательский анализ данных (EDA) о вакансиях в сфере Data Science за 3 года. Цель — выявить ключевые факторы, влияющие на зарплатную вилку, и понять, в каких компаниях выгоднее работать специалистам разных грейдов (Middle, Senior).

## 🛠️ Стек технологий и инструменты
* **Язык:** Python
* **Работа с данными:** Pandas, Numpy
* **Визуализация:** Matplotlib, Seaborn
* **Статистический анализ:** Scipy (корреляция Спирмена, тест Левена, преобразование Бокса-Кокса), Statsmodels (One-way ANOVA, Tukey HSD).

## 📊 Этапы исследования и методология

1. **Предобработка данных (Data Cleaning):**
   * Закодировали порядковые категориальные переменные (`experience_level`, `company_size`) в числовой формат для корректного проведения математических расчетов.
   * Выявили и удалили экстремальные выбросы (зарплаты выше 300 000 USD), которые могли исказить результаты статистических тестов.

2. **Разведочный анализ (EDA) и Корреляция:**
   * Построили распределение вакансий по грейдам и размерам компаний.
   * Использовали **коэффициент корреляции Спирмена** (так как данные порядковые), чтобы оценить силу связи между зарплатой, опытом и размером компании.

3. **Дисперсионный анализ (ANOVA):**
   * Разделили датасет на две подвыборки: Middle и Senior.
   * Для проверки нормальности распределения (необходимое условие ANOVA) использовали визуальный анализ и **преобразование Бокса-Кокса** (для мидлов).
   * Проверили гомоскедастичность (равенство дисперсий) с помощью **теста Левена**.
   * Провели **One-way ANOVA** и **апостериорный тест Тьюки (Tukey HSD)** для попарного сравнения групп.

## 💡 Ключевые выводы (Бизнес-инсайты)

* **Что влияет на зарплату сильнее всего?** 
  Уровень опыта (грейд). Корреляция Спирмена показала сильную связь (0.55), в то время как размер компании влияет на зарплату крайне слабо (0.10).
  
* **Портрет рынка:** 
  Большинство вакансий сосредоточено в компаниях среднего размера (M) — более 300 предложений. Самый востребованный грейд на рынке — Senior (SE).

* **Куда выгоднее идти Middle-специалисту?**
  Для мидлов размер компании имеет статистически значимое значение (p-value < 0.05). Пост-хок тест Тьюки выявил, что компании размера **L и M** предлагают значительно более высокие зарплаты, чем **S**. Мидлам не рекомендуется рассматривать маленькие компании в первую очередь.

* **Куда выгоднее идти Senior-специалисту?**
  Для сеньоров размер компании **не имеет значения**. ANOVA не выявила значимых различий в зарплатах между компаниями разных размеров (p-value > 0.05). Высококвалифицированные специалисты получают конкурентную зарплату в компаниях любого масштаба.
